# Deployment

## Local

`pnpm dev` (UI + worker) or `docker compose -f docker/compose.yaml up --build`. Both bind to `127.0.0.1`.

## Any container host (VPS, Fly.io, Railway, Render)

The image (`ghcr.io/santoshbpathak/webaudit-ai` on tagged releases, or `docker/Dockerfile`) runs the UI and a worker.

| Variable                     | Purpose                                                                                                                          |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `WEBAUDIT_ACCESS_TOKEN`      | **Required** when exposed. 16+ random characters. Open the app once with `?token=…`; API clients send `Authorization: Bearer …`. |
| `WEBAUDIT_DATA_DIR`          | Defaults to `/data` — mount a persistent volume.                                                                                 |
| `WEBAUDIT_ROLE`              | `all` (default), `web` or `worker` for separate replicas.                                                                        |
| `WEBAUDIT_CHROME_NO_SANDBOX` | Set to `1` only if your platform forbids Chrome's sandbox.                                                                       |
| AI variables                 | See [ai.md](ai.md).                                                                                                              |

Give the container ≥ 2 GB RAM and ≥ 1 GB shared memory for Chromium.

### Fly.io example

```bash
fly launch --no-deploy --dockerfile docker/Dockerfile
fly volumes create webaudit_data --size 3
fly secrets set WEBAUDIT_ACCESS_TOKEN=$(openssl rand -hex 16)
# fly.toml: [mounts] source="webaudit_data" destination="/data"; [[vm]] memory="2gb"
fly deploy
```

## Read-only public demo

Run the image with `WEBAUDIT_DEMO=1` and `WEBAUDIT_DATA_DIR=/app/examples/demo-data`. Scanning, cancellation, deletion and AI are disabled; the bundled Fernhill audits (generated by `pnpm examples`) are browsable. No token is required because the instance cannot fetch anything — this is the safe way to share a live demo without letting strangers use your server to scan the internet.
